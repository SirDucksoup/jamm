Открыть приложение / Open the app →

📖 Как установить (по-русски)

🤖 Android (Chrome)

Открой приложение по кнопке выше → меню «⋮» → «Установить приложение».

🍏 iPhone / iPad (Safari)

Открой приложение по кнопке выше → кнопка «Поделиться» → «На экран „Домой“».

💻 Windows (Chrome / Edge)

Открой приложение по кнопке выше → значок «Установить» справа в адресной строке (или меню «⋮» → «Установить приложение»). Ярлык появится в меню «Пуск».

🍎 macOS

Safari 17+: открой приложение → меню «Файл» → «Добавить в Док».
Chrome: меню «⋮» → «Установить страницу как приложение».

После установки: своё окно, иконка «Jamm» на рабочем столе и работа без интернета.

Перенос своих песен/настроек: ⚙️ Настройки → «💾 Скачать копию» → перекинуть файл «мои-данные.json» на другое устройство → там же «📂 Восстановить…».

📖 How to install (English)

🤖 Android (Chrome)

Open the app via the button above → the «⋮» menu → “Install app”.

🍏 iPhone / iPad (Safari)

Open the app via the button above → the Share button → “Add to Home Screen”.

💻 Windows (Chrome / Edge)

Open the app via the button above → click the “Install” icon at the right end of the address bar (or the «⋮» menu → “Install app”). A shortcut appears in the Start menu.

🍎 macOS

Safari 17+: open the app → menu “File” → “Add to Dock”.
Chrome: the «⋮» menu → “Install page as app”.

After installing: its own window, a “Jamm” icon on your desktop and works offline.

To move your songs/settings: ⚙️ Settings → “💾 Download backup” → copy the “мои-данные.json” file to the other device → “📂 Restore…” there.
