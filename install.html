📖 How to install (English)

🤖 Android (Chrome)

Open the app via the button above → the «⋮» menu → “Install app”.

🍏 iPhone / iPad (Safari)

Open the app via the button above → the Share button → “Add to Home Screen”.

💻 Windows (Chrome / Edge)

Open the app via the button above → click the “Install” icon at the right end of the address bar (or the «⋮» menu → “Install app”). A shortcut appears in the Start menu.

🍎 macOS

Safari 17+: open the app → menu “File” → “Add to Dock”.
Chrome: the «⋮» menu → “Install page as app”.

After installing: its own window, a “Jamm” icon on your desktop and works offline.

To move your songs/settings: ⚙️ Settings → “💾 Download copy” → copy the “my-data.json” file to the other device → “📂 Restore…” there.

📖 Як встановити (українською)

🤖 Android (Chrome)

Відкрийте застосунок кнопкою вище → меню «⋮» → «Встановити застосунок».

🍏 iPhone / iPad (Safari)

Відкрийте застосунок кнопкою вище → кнопка «Поділитися» → «На екран „Домів“».

💻 Windows (Chrome / Edge)

Відкрийте застосунок кнопкою вище → значок «Встановити» праворуч в адресному рядку (або меню «⋮» → «Встановити застосунок»). Ярлик з’явиться в меню «Пуск».

🍎 macOS

Safari 17+: відкрийте застосунок → меню «Файл» → «Додати в Док».
Chrome: меню «⋮» → «Встановити сторінку як застосунок».

Після встановлення: власне вікно, іконка «Jamm» на робочому столі та робота без інтернету.

Переніс своїх пісень/налаштувань: ⚙️ Налаштування → «💾 Завантажити копію» → перекинути файл «мої-дані.json» на інший пристрій → там же «📂 Відновити…».
