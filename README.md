# Jamm

**EN:** A guitar helper with zero theory required: fretboard with scales and chords, circles,
song builder, tuner, metronome, transposing. Installs on phones and computers, works offline.

**UK:** Гітарний помічник без теорії: гриф з гамами та акордами, круги, збірка пісні,
тюнер, метроном, транспонування. Встановлюється на телефон і комп'ютер, працює офлайн.

- **Open / Відкрити:** <https://sirducksoup.github.io/jamm/>
- **How to install (EN/UK) / Як встановити (EN/UK):** <https://sirducksoup.github.io/jamm/install.html>

Works in Chrome / Edge / Safari / Firefox on Android, iPhone/iPad, Windows, macOS, Linux.
Працює в Chrome / Edge / Safari / Firefox на Android, iPhone/iPad, Windows, macOS, Linux.
