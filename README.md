# Джем (Jamm) · Гитарный помощник

**RU:** Приложение для гитариста без теории: гриф с гаммами и аккордами, круги, сборка песни,
тюнер, метроном, транспонирование. Ставится на телефон и компьютер, работает офлайн.

**EN:** A guitar helper with zero theory required: fretboard with scales and chords, circles,
song builder, tuner, metronome, transposing. Installs on phones and computers, works offline.

- **Открыть / Open:** <https://sirducksoup.github.io/jamm/>
- **Как установить / How to install (RU/EN):** <https://sirducksoup.github.io/jamm/install.html>

Работает в браузере Chrome / Edge / Safari / Firefox на Android, iPhone/iPad, Windows, macOS, Linux.
Works in Chrome / Edge / Safari / Firefox on Android, iPhone/iPad, Windows, macOS, Linux.
